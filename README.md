## 阅读顺序

先读 [DOPAMATRIX_CONTEXT.md](./DOPAMATRIX_CONTEXT.md)，了解当前 DopaMatrix 的基础能力：DAM、Story DSL、渲染、审批和交付导出。

再读 [product-ops/README.md](./product-ops/README.md)，了解下一层要补齐的能力：发布中台、账号体系、询盘归因、客户报告和爆款基因反馈。

如果要继续维护这些规划，先看 [product-ops/00-documentation-standard.md](./product-ops/00-documentation-standard.md)，再更新对应专题文档、[product-ops/DECISIONS.md](./product-ops/DECISIONS.md) 或 [product-ops/TODO.md](./product-ops/TODO.md)。

## 边界说明

当前代码已经能生产和交付视频变体，但还没有完整的发布、询盘、报告和增长学习闭环。`product-ops` 目录中的文档是规划记录，不代表这些功能已经全部落地。
